# Agent Instructions for UI Work

Before proposing, generating, or revising any UI:
1. read `docs/design/ui-design-policy.md`
2. read `docs/design/ui-review-checklist.md`
3. read the relevant Apple Human Interface Guidelines materials in this repository
4. self-check the proposal against all three before finalizing

Never produce UI based only on generic modern app trends.
Never prioritize visual novelty over Apple usability and accessibility.

## Mandatory Output Format
For every UI-related output, include these exact headings:

- Purpose
- Apple HIG Basis
- NeXT / OPENSTEP / GNUstep Influence
- Layout Description
- Interaction Behavior
- Visual Styling Notes
- Accessibility Notes
- Implementation Considerations
- Self-Check Result

Do not omit these headings.

## Final Rule
If Apple HIG and the intended NeXT / OPENSTEP / GNUstep inspired visual direction appear to conflict, preserve Apple usability, accessibility, and platform behavior first.
